ツリーの操作
空白をダブルクリック（スマホはダブルタップ）… タスク追加
ノードをダブルクリック / Enter … 名前を編集
左の ○ … 未着手 → 進行中 → 完了
まわりの ●（上下左右・四隅）をドラッグ … 他ノードへ接続（空白で離すと子タスク）
線をクリック → 両端のピンクの ● をドラッグ … つなぐ位置を変更
一覧の ⋮⋮ をドラッグ … 順番の入れ替え（階層はそのまま）
右上の「ツール ▾」 … ツールバーの行を開く / 閉じる
「ツリー」「縦並び」 … 整列　「保存」 … 今のボックスの位置を保存　「手動」 … 保存した位置に戻す
ノードを選択 → 下のバーで状態・子追加・詳細・削除
Tab 子追加　Space 状態　Del 削除　D 詳細
1 2 3 … 優先度 高・中・低（0 で解除）
Shift+ドラッグ … 配下ごと移動
背景ドラッグ … 移動　ホイール / 2本指 … ズーム
ガント：詳細で開始日・終了日を入れると表示
色：枠線＝状態、箱の塗り＝階層（親・子・孫・ひ孫）
同期：右上の「ログインして同期」から、PCとスマホで同じアカウントにログイン
タイトル：クリックで名前を変更　Ctrl+Z 元に戻す
